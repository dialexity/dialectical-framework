### Case particulars carried into the returning session

The person's own specifics — numbers, splits, named events — that
only carryover could supply. Facts the person RE-STATED in the
returning session are excluded from the denominator: repeating them
back is transcript reading, not memory.

This is the probe the framework's own abstraction works against:
poles are capped near seven words and deduped, so a tetrad carries
the shape of a tension and none of the case. A2 scoring BELOW a
prose journal here is the expected result without a grounding lane,
and is a finding about the graph, not about the model.

TWO columns, and the pair is the diagnosis:
  memory  — the fact was in the artifact the session was HANDED
            (rendered graph dump for A2, journal for A1.7).
  used    — the assistant's reply actually referenced it.
A low `memory` is a STORAGE defect: the carryover never held the
person's case. A high `memory` with a low `used` is a PROMPT defect:
it was there to read and the reply spoke in generalities anyway.
Collapsing the two into one number hides which fix applies.

`n/a` under memory = the arm carries nothing by construction
(A0/A1): an absence of capability, never a zero. `--` = the arm DOES
carry something and it was not recorded, which is a harness gap and
must not be read as an empty memory. Records saved before
`carryover_in` existed show `--` on every carrying arm.

==============================================================================
Reading this report
==============================================================================

1. Check the validity section FIRST. A collapsed A2 arm or a
   single-tier run bounds what any number below can mean.
2. Check n before believing a row. One replicate cannot distinguish a
   delta from judge variance — see the n=1 warning above the table.
3. A delta only counts if the machine scores agree with the judge.
   Where they disagree, trust the machine score — it cannot be
   flattered by eloquence.
4. 'depreciating' deltas will shrink to zero as models improve; do
   not build the product claim on them. 'durable' deltas are the
   claim. 'absent' means the framework added nothing measurable.
5. On poor-fit controls the framework SHOULD show no gain. A win
   there means the judge is rewarding structure, and the rubric
   needs revision before any other number is trusted.
